# Advanced EDA & Feature Engineering — Project 1

## 📌 Project Overview

This project focuses on Advanced Exploratory Data Analysis (EDA) and Feature Engineering using Python.

The objective is to understand the dataset, identify patterns and relationships, handle data quality issues, and prepare meaningful features for machine learning.

## 🎯 Objectives

- Perform data cleaning and preprocessing
- Analyze missing values
- Detect and handle outliers
- Perform univariate and bivariate analysis
- Analyze relationships between features
- Visualize important patterns in the dataset
- Perform feature engineering
- Prepare the data for machine learning

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## 🔍 Exploratory Data Analysis

The notebook covers:

- Dataset structure and dimensions
- Data types
- Missing value analysis
- Descriptive statistics
- Distribution analysis
- Outlier detection
- Correlation analysis
- Data visualization

## ⚙️ Feature Engineering

The project includes techniques such as:

- Handling missing values
- Encoding categorical variables
- Feature transformation
- Creating new features
- Feature selection
- Data preprocessing
